# دليل التشغيل — محتاج صنايعي (الخطة المجانية)

التطبيق شغال على **Firebase Spark (مجاني بالكامل — من غير كارت)**:
- الدخول: بريد وكلمة سر أو Google (بدون SMS). رقم الموبايل بيتسجل في البيانات، ورقم واحد لكل حساب.
- مفيش Cloud Functions ولا Cloud Storage: كل الكتابة من التطبيق ولوحة التحكم مباشرة، و**قواعد الأمان** (`firestore.rules`) هي اللي بتتحكم في الحالات والعمولة والتقييمات والصلاحيات — ومختبرة بـ 13 اختبار على محاكي Firestore الحقيقي.
- الصور: بتتضغط وتتخزن في قاعدة البيانات (`media/{id}`)، وصور البطاقة للإدارة فقط.
- الإشعارات: **داخل التطبيق** (بانر وقت ما التطبيق مفتوح + صندوق الإشعارات). إشعارات الموبايل والتطبيق مقفول محتاجة خطة Blaze.

## الخطوات (مرة واحدة)

### 1) Firebase Console
1. مشروع `mehtag-sanaye` (موجود) → **Authentication → Get started**.
2. **Sign-in method**: فعّل **Email/Password** و **Google** (اختار بريد الدعم واضغط Save).

### 2) مفتاح حساب الخدمة → GitHub
1. Firebase → ⚙️ **Project settings → Service accounts → Generate new private key** → هينزل ملف JSON.
2. GitHub → المستودع → **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `FIREBASE_SERVICE_ACCOUNT`
   - Secret: افتح ملف الـJSON بأي محرر نصوص وانسخ كل محتواه والصقه.

### 3) تشغيل الإعداد
GitHub → **Actions → Setup & deploy Firebase → Run workflow**. هيعمل لوحده:
- ينشئ قاعدة البيانات (لو مش موجودة) ويفعّل الدخول بالبريد
- يسجل تطبيق الويب ويجهز لوحة التحكم
- ينشر قواعد الأمان والفهارس ولوحة التحكم على `https://mehtag-sanaye.web.app`
- يضيف 14 مهنة وخدماتها و27 محافظة والإعدادات (عمولة 5%)
- يحدّث إعدادات Android ويبني APK جديد تلقائيًا

لو أي خطوة ماتمتش أوتوماتيك، ملخص التشغيل بيقول بالظبط المطلوب يدويًا.

### 4) حساب المدير
افتح `https://mehtag-sanaye.web.app` → اكتب `rafatsaeed719@gmail.com` وكلمة سر → **أول مرة؟ إنشاء حساب صاحب التطبيق** → افتح Gmail واضغط رابط التأكيد → ارجع واضغط **دخول**. (أو **الدخول بحساب Google** مباشرة.)
بعدها من **الإعدادات** حط بيانات InstaPay وأرقام الدعم.
